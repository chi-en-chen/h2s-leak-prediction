# 油井硫化氢（H2S）泄漏扩散预测平台

基于**美国环保署（US EPA）SLAB 重气扩散模型**的油井 H2S 泄漏扩散分析与可视化工具。
用于评估硫化氢泄漏后云团随时间的扩散过程：输入泄漏源参数与现场微气象要素，
即可计算 1 / 3 / 5 / 15 分钟等时刻的云团厚度、横向铺展范围与空间浓度分布，
并通过网页平台完成可视化与传感器验证。

> 说明：本工具用于工程分析与应急演练辅助，不替代专业安全评估与法定检测。

## 功能特性

- **SLAB 重气扩散计算**：封装 EPA SLAB 模型（`Slab.exe`），自动生成工况输入、
  调用计算、解析输出，并按 SLAB 文档公式重构三维浓度场 C(x,y,z,t)。
- **分时段云团特征**：输出 1 / 3 / 5 / 15 分钟时刻的云团厚度、横向铺展范围、
  空间浓度分布与浓度热力云图。
- **扩散动态动画**：生成云团随时间演变的 GIF 动画。
- **四传感器监测验证**：4 个传感器分别位于井口正北 / 正西 / 正南 / 正东、
  距井口 60 m（构成边长 60 m 正方形），结合传感器读数进行模型验证。
- **应急风险分区可视化**：浓度分级渲染（低浓度浅黄 → 中浓度橙 → 高浓度深红）、
  1 / 10 / 100 ppm 等值线、核心应急隔离区（红实线）、警戒疏散区（黄虚线）与疏散路线。
- **网页平台**：客户可直接在浏览器中输入参数、查看预测结果并下载数据。

## 目录结构

```
├── slab_h2s_lib.py           # SLAB 模型封装库（输入生成/调用/输出解析/浓度场重构）
├── h2s_leak_analysis.py      # H2S 泄漏扩散分析（浓度-时间曲线/危害距离/足迹）
├── h2s_sensor_analysis.py    # 四传感器浓度预测与实测验证
├── h2s_time_slices.py        # 分时段（1/3/5/15 min）云团特征与热力云图、动画
├── h2s_risk_visual.py        # 应急风险分区核心可视化
├── Slab.exe / SLAB.FOR       # EPA SLAB 模型程序与源码（公有领域）
├── SLAB.RME / INPR1-4        # SLAB 说明文档与官方示例输入
├── slabbat.bat / SLABfc.bat  # SLAB 命令行批量运行 / 结果对比脚本
├── web_platform/             # 网页平台（Flask）
│   ├── app.py / runner.py    # Web 服务与后台计算调度
│   ├── templates/ static/    # 前端页面
│   └── jobs/                 # 每次计算的结果（自动生成，不入库）
├── 启动网页平台.bat          # 一键启动网页平台
├── 开启局域网访问.bat        # 一键放行防火墙，供局域网访问（需管理员）
└── requirements.txt          # Python 依赖
```

## 环境要求

- Windows 10/11（SLAB 模型为 Windows 可执行程序）
- Python 3.10+（开发验证环境为 3.14）
- Python 依赖：`pip install -r requirements.txt`（flask / numpy / scipy / matplotlib）

## 快速开始

### 方式一：网页平台（推荐给客户使用）

1. 双击 `启动网页平台.bat`，浏览器自动打开 `http://127.0.0.1:5000`；
2. 在左侧输入泄漏源参数（泄漏速率、持续时间、液池面积）与微气象要素
   （风速、风向、气温、气压、湿度、大气稳定度）；
3. 点击「开始计算」，实时查看进度；完成后查看核心可视化、热力云图、
   扩散动画、传感器读数与文件下载。

### 方式二：命令行脚本

```bat
:: 完整分析（生成工况 + 运行 SLAB + 分析）
python h2s_leak_analysis.py

:: 传感器分析与模型验证（--demo-data 生成示例读数）
python h2s_sensor_analysis.py --demo-data

:: 分时段云团特征 + 热力云图 + 动画
python h2s_time_slices.py
```

## 局域网共享访问（让其他电脑访问平台）

1. 右键 `开启局域网访问.bat` → “以管理员身份运行”，放行防火墙 5000 端口（一次即可）；
2. 双击 `启动网页平台.bat`，启动窗口会显示局域网访问地址（形如 `http://192.168.x.x:5000`）；
3. 同事连接同一局域网后，用浏览器打开该地址即可使用。

> 平台暂无登录口令，请仅在可信网络内使用；外网访问需路由器端口映射或内网穿透，并建议增加访问控制。

## 计算输出

网页端每个任务在 `web_platform\jobs\<任务ID>\` 下自动保存：

- `fig6_核心可视化_四时刻.png`：传感器点位 + 重气云团 + 等值线 + 应急分区 + 疏散路线
- `fig5_浓度热力云图_四时刻.png`：1/3/5/15 分钟地面浓度分布
- `h2s_扩散动画.gif`：扩散动态动画
- `fig1~fig3`：传感器布局 / 浓度足迹 / 四传感器时间序列
- `传感器读数汇总.csv`、`h2s_sensor_summary.csv`、`h2s_time_slices_summary.csv`
- `剖面_<时刻>min.csv`：各时刻浓度剖面数据

## 传感器布局

四个传感器分布在油井四个方位、距井口 60 m（构成边长 60 m 的正方形）：

| 编号 | 方位 | 坐标（E/N, m） |
| ---- | ---- | ---- |
| S1 | 正北 | (0, +60) |
| S2 | 正西 | (-60, 0) |
| S3 | 正南 | (0, -60) |
| S4 | 正东 | (+60, 0) |
