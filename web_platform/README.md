# H2S 泄漏扩散预测平台（网页版）

基于美国 SLAB 重气扩散模型开发的油井硫化氢（H2S）泄漏扩散预测与可视化平台。
客户在网页中输入泄漏源参数与现场微气象要素，即可在线完成 SLAB 计算，并查看
1/3/5/15 分钟的扩散云团、浓度热力云图、扩散动画、传感器读数与应急风险分区。

## 快速启动

方式一（推荐）：双击本目录下的 `启动网页平台.bat`，浏览器会自动打开平台页面。

方式二（命令行）：
```bat
cd /d 本项目根目录（SLAB 文件夹）
python -X utf8 web_platform\app.py
```
然后浏览器访问：http://127.0.0.1:5000

> 注意：请勿关闭启动窗口；计算依赖本目录下的 `Slab.exe`。

## 局域网共享访问（让其他电脑访问本平台）

1. 右键 `开启局域网访问.bat`，选择「以管理员身份运行」，自动放行防火墙 5000 端口（只需执行一次）；
2. 双击 `启动网页平台.bat` 启动平台，启动窗口会显示本机局域网访问地址
   （形如 `http://192.168.x.x:5000`），同时自动生成 `web_platform\访问地址.txt`；
3. 把该地址发给同事，同事与本机连接同一局域网（同一路由器/WiFi）后，用浏览器打开即可，
   使用方式与本机完全相同。

> 提示：
> - 请确保本机与同事连接的是同一局域网，且公司网络未开启「访客隔离」；
> - 平台目前无登录口令，请仅在可信的办公网络内共享使用；
> - 若需通过互联网访问，需要路由器端口映射或内网穿透工具，并建议增加访问控制。
## 使用方法

1. 左侧「参数输入」填写泄漏源参数、现场微气象与计算设置；
2. 点击「开始计算」，页面实时显示进度与日志；
3. 计算完成后，通过选项卡查看结果：
   - 核心可视化：传感器点位（正北/正西/正南/正东，距井口 60 m）、
     半透明重气云团（低浓度浅黄→中浓度橙→高浓度深红）、
     1/10/100 ppm 等值线、红色实线核心应急隔离区、黄色虚线警戒疏散区、疏散路线；
   - 浓度热力云图：1/3/5/15 分钟地面浓度分布；
   - 扩散动画：云团随时间演变的 GIF 动画；
   - 传感器读数：四传感器在各时刻的浓度预测（ppm / mg/m3）与正常/告警状态；
   - 云团特征：各时刻峰值、1ppm 前锋距离、云团厚度、最大宽度、覆盖面积；
   - 文件下载：全部图片与 CSV 数据（浓度剖面、汇总表）。

## 输入参数说明

| 分组 | 参数 | 说明 |
| ---- | ---- | ---- |
| 泄漏源 | 泄漏速率 qs | H2S 泄漏速率，kg/s |
| 泄漏源 | 持续泄漏时间 | 连续泄漏持续时间，min |
| 泄漏源 | 液池面积 as | 地面蒸发池面积，m²（源类型为蒸发池时有效） |
| 泄漏源 | 源类型 | 地面蒸发池 / 垂直喷口 |
| 气象 | 环境风速 ua | 现场实测风速，m/s |
| 气象 | 风向（来向） | 北/东北/东/东南/南/西南/西/西北 或自定义角度 |
| 气象 | 环境气温 | °C，内部换算为 K |
| 气象 | 环境气压 | hPa，用于 ppm→mg/m³ 换算 |
| 气象 | 相对湿度 | % |
| 气象 | 大气稳定度 | A（强不稳定）～ F（稳定），默认 D（中性） |
| 计算 | 分析高度 | 呼吸带高度，默认 1.5 m |
| 计算 | 分析时刻 | 逗号分隔的分钟数，默认 1,3,5,15 |
| 计算 | 扩散动画 | 是否生成 GIF 动画（约多耗时 40 秒） |
| 计算 | 动画时长 | 动画时间范围，min |

## 输出结果

每个计算任务在 `web_platform\jobs\<任务ID>\` 目录下生成：

- `fig6_核心可视化_四时刻.png` / `fig6_核心可视化_<末时刻>min.png`：核心可视化图
- `fig5_浓度热力云图_四时刻.png`：浓度热力云图
- `h2s_扩散动画.gif`：扩散动态动画
- `fig1_传感器布局.png` / `fig2_浓度足迹_多时刻.png` / `fig3_四传感器时间序列.png`
- `传感器读数汇总.csv` / `h2s_sensor_summary.csv` / `h2s_time_slices_summary.csv`
- `剖面_<时刻>min.csv`：各时刻中心线与峰值位置横向剖面数据

## 技术说明

- 前端：HTML + CSS + JavaScript（原生 fetch，无构建依赖）
- 后端：Flask + 后台线程任务，任务状态实时轮询
- 计算：复用本项目已有 SLAB 分析脚本
  （`slab_h2s_lib.py`、`h2s_sensor_analysis.py`、`h2s_time_slices.py`、`h2s_risk_visual.py`）
- 依赖：Python 3.10+、flask、numpy、scipy、matplotlib
